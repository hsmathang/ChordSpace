
# Guion visual de 65 diapositivas para la defensa de tesis

## Modelo computacional para la exploración de acordes en la composición musical

**Versión de trabajo:** basada en el guion maestro, la maqueta de guion, la idea conversada, la tesis y el artículo revisado.  
**Criterio visual:** muy poco texto por diapositiva, títulos serios, uso dominante de esquemas, flechas, imágenes, diagramas, secuencias animadas y transiciones limpias.  
**Nota importante:** la **portada debe ser solo texto**, sobria, sin imagen.

---

## Cómo leer este documento

Cada diapositiva contiene:

- **Título sugerido**
- **Visual principal**
- **Idea que debe comunicar**
- **Apoyo oral**
- **Animación sugerida**

Este documento no es la presentación final. Es una **arquitectura visual completa** de la charla.  
Muchas diapositivas pueden compactarse o dividirse luego, pero aquí se fija una versión amplia de **65 diapositivas**, incluyendo **referencias** y **agradecimientos**.
